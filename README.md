# Pixel Dungeon Desktop Remake

An offline Windows desktop adaptation inspired by the original Pixel Dungeon, using artwork from the original project.

## Download and play

Download PixelDungeonDesktopSource.zip from this repository and extract it. Open the extracted folder, then double-click desktop/Play Pixel Dungeon.bat. Java Development Kit (JDK) 17 or newer is required.

The launcher uses a JDK path configured for the author's computer. If your JDK is installed elsewhere, edit the JAVA_HOME line in the batch file.

## Controls

- Arrow keys or WASD: move
- G: pick up an item
- E: eat food
- P: drink a healing potion
- I: open inventory
- Ctrl+S or Esc: save
- L: load a saved game from the title screen
- 1–4: choose Warrior, Mage, Rogue, or Huntress

This is a compact desktop remake, not the complete original Android game or a direct port of its full codebase. The source package contains the adaptation, original project sources and assets, and license notices.
